# RP-StoneCobbler

![icon](./icon.png)

**Turn `Stone` into `Pebble` using a Stonecutter, and recombine Pebbles into `Cobblestone`!**  
This is a small utility Fabric mod for survival-friendly recycling of stone blocks.

---

## 🧱 Features

- Convert `Stone` into `Pebble` using a **Stonecutter**
- Combine `Pebble` ×4 in a **2×2 crafting grid** (even in inventory) to get `Cobblestone`

---

## 🛠 Compatibility

- **Minecraft**: 1.21.4  
- **Fabric Loader**: 0.16.10 or later  
- **Java**: 21 or later
